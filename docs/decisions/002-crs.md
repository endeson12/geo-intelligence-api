# ADR 002 — CRS canônico EPSG:4326

**Status:** aceito

## Contexto

Fontes geográficas podem usar sistemas de referência diferentes. Misturá-los silenciosamente produz distâncias e posições incorretas.

## Decisão

O contrato de entrada aceita somente longitude/latitude WGS84 (`EPSG:4326`) e rejeita coordenadas fora das faixas válidas. Transformações devem ocorrer no pipeline antes da importação e registrar o CRS de origem.

## Consequências

O contrato fica simples e interoperável com GeoJSON, mas a API não corrige CRS desconhecido. Uma fonte institucional precisa documentar transformação, precisão e validação amostral.
